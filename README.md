# ARdex (Aeron Region Dex)

dex.aeronregion.net: Pokédex, moves, abilities, items, type chart and team tools, with Cobbleverse spawns and movepools.

## Run it locally
```
npm install
npm run dev        # http://localhost:4321
npm run build      # static site in dist/
```
Pushing to `main` deploys automatically (Cloudflare Workers Builds). The commit's check run shows when the deploy has finished.

## Tools: how they work
- **Teambuilder** (`/team/`): full Showdown sets with live stats. Teams are saved in the browser (`localStorage` key `ardex-teams`).
  - Up to 14 Pokémon per team. **+** adds an empty slot with the Pokémon list open.
  - Formats: all games, Champions, Cobbleverse, gens 9/8/7. Champions uses Stat Points: 66 total, 32 max per stat, Lv. 50.
  - Typing `+` or `-` after a stat's EVs sets the nature, like Showdown.
  - Stat bars follow Showdown's formula and are sized as at Lv. 100.
  - Sharing: **Copy link** puts the team in the URL (`/team/?team=<base64>&name=`). **Create PokéPaste** posts to pokepast.es. **Check coverage** opens the Coverage checker with the team.
- **Coverage checker** (`/coverage/`): defense by member and moveset coverage for up to 14 Pokémon. It accepts the same `?team=` links.
- **Light/dark mode**: stored in a `theme` cookie on `.aeronregion.net`, so it's shared with the main site, with `localStorage` and the system setting as fallbacks.

## Data
The site reads the JSON in `src/data/` and in `public/`:
- `public/search-index.json`: species, moves and learnsets for the search and tools.
- `public/tb.json`: base stats, ability, move and item details for the tools.
- `public/names.json`

All of these are generated by `scripts/prepare.mjs` and committed, so Cloudflare doesn't download anything when it builds.

Sources:
- **Pokémon Showdown** (via `@pkmn/dex`): stats, types, abilities, moves (including Let's Go, Z- and Max moves), move text, items, learnsets for every game.
- **PokéAPI** CSVs: EV yield, catch rate, growth rate, egg cycles, height, Pokédex entries, main-game locations, item text. Sprites and artwork are loaded from PokéAPI's sprite repo on GitHub.
- **Cobbleverse pack files**: spawns, drops and Cobblemon movepools.

### Updating after a Cobbleverse update
1. From the Modrinth profile, unzip each of these into its own folder:
   `mods/Cobblemon-fabric-*.jar`, `mods/mega_showdown-*.jar`, `datapacks/COBBLEVERSE-DP-v*.zip`
2. Run, listing the folders in that order (later ones override earlier ones):
   ```
   node scripts/cobbleverse.mjs 1.8.0 path/to/cobblemon path/to/mega_showdown path/to/cobbleverse-dp
   npm run data
   ```
3. Commit the changed files in `src/data/` and `public/`, and push.

To refresh only the Showdown/PokéAPI data: `npm update @pkmn/dex`, delete `.cache/*.csv`, then `npm run data`.

## Known gaps
- Cobbleverse movepools come from the pack's species files. Those list egg moves (for example Swampert's Wide Guard) even though there's no breeding on the server, so some moves show as learnable when they aren't in game.
- `src/styles/global.css` has grown by adding override blocks at the end. If it gets hard to work with, fold those blocks back into the rules they override.
